# Araşdırma (recon)

İstinad saytlarının öyrənilməsi: `recon.md` (ekranlar, axınlar, komponentlər, "Jeparla-ya nə
götürürük") və `features.csv` (feature, area, priority, reference, jeparla, notes).

Qaydalar: yalnız ictimai səhifələr, insan sürəti ilə; kod, şəkil, mətn, loqo götürülmür.
Ekran görüntüləri `screens/` qovluğunda saxlanılır və repoya düşmür (`.gitignore`).
