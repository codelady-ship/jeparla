## Aylıq hesabat (4-cü həftənin sonu, 45 dəq.)

1. Hər post üçün: reach, izləyici olmayanlara çatma payı, saves/reach, sends/reach, link klikləri.
2. Reels: orta izləmə müddəti, sona qədər baxılma; hansı hook işləyib.
3. Satıcı: göndərilən DM, cavab, qeydiyyat, yerləşdirilmiş mağaza (outreach cədvəlindən).
4. Saytda: `utm_source=instagram/tiktok` ilə gələn sessiya və WhatsApp klikləri.
5. Nəticə: ən yaxşı 3 və ən zəif 3 post; növbəti ay üçün sütun paylarını və dərc vaxtını dəyiş;
   ilk real KPI hədəflərini yaz (bazaya görə, uydurmadan).
6. Hesabat #101-ə şərh kimi yazılır (rəqəmlər real, şəxsi məlumat yox).
